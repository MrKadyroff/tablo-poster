# Обновление eCash Tablo без потери настроек

## Проблема, которую это решает
Раньше при обновлении вы копировали всю папку на компьютер — и настройки точки
(IP табло, SSID, выбранные валюты, раскладка, Telegram) **затирались**, приходилось
настраивать заново.

Теперь обновление выполняется скриптом, который **сохраняет настройки точки** и
обновляет только программу. Версия видна в меню трея: «eCash Tablo  vX.Y.Z».

## Что сохраняется при обновлении
Скрипт `tools\update.ps1` не трогает эти файлы/папки в установленной версии:
- `appsettings.json` — точка, Telegram, Wi-Fi SSID и т.п.
- `config\` — `screen.xml`, `config\points\*.json` (IP, размер экрана, тип контроллера)
- `layout\points\` — раскладка и валюты по точкам
- `content\points\` — курсы и сгенерированные изображения

Всё остальное (программа, библиотеки, флаги/логотипы в `content\common\`) — обновляется.

## Централизованный способ (рекомендуется)
1. Заведите **одну общую папку**, доступную всем кассам: сетевую (`\\SERVER\ecash\latest`)
   или облачную (Яндекс.Диск / Google Drive / OneDrive — папка, синхронизируемая на всех ПК).
2. Каждый релиз кладите **новую сборку целиком** в эту папку (там должен лежать `eCashTablo.exe`).
3. На каждом ПК один раз пропишите путь к этой папке в файле
   `tools\update-source.txt` (сейчас там заглушка `\\SERVER\ecash\latest`).
4. Чтобы обновить точку — кассир/админ **двойным кликом** запускает `tools\Обновить.bat`.
   Скрипт сам: сравнит версии, остановит программу, обновит файлы (сохранив настройки),
   запустит программу снова. Если версия не новее — ничего не делает.

Так «контроль версий» получается централизованным: в общей папке всегда лежит актуальная
версия, а каждый ПК обновляется одним кликом и не теряет настройки.

## Ручной способ (без общей папки)
Запустить из командной строки в папке установки:
```
powershell -ExecutionPolicy Bypass -File tools\update.ps1 -Source "D:\путь\к\новой\версии"
```
`-Source` — папка с новым `eCashTablo.exe` (например, распакованный архив или USB).
Добавьте `-Force`, чтобы переустановить ту же версию.

## Как выпускать новую версию (для разработчика)
1. Поднимите номер в `LedImageUpdaterService.csproj` → `<Version>` (например, `1.0.1`).
2. Соберите релиз:
   ```
   dotnet publish LedImageUpdaterService.csproj -c Release -r win-x64
   ```
3. Содержимое папки публикации положите в общую папку обновлений (п. «Централизованный способ»).
4. На точках запускают `Обновить.bat` — версия определится по `eCashTablo.exe` автоматически.

## Журнал
Результат каждого обновления пишется в `tools\update.log`.
