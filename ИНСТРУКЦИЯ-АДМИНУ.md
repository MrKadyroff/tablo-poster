# eCash Tablo — инструкция администратору

Администратор настраивает табло: какие валюты, как выглядят, куда отправлять.
Кассиру это окно недоступно — оно открывается по паролю.

## Как открыть настройки
Возле часов найдите синий значок с буквой **e** → клик **правой** кнопкой →
**«Настройки (администратор)…»** → введите пароль.

> _скрин: меню по правому клику + окно пароля_

## Что наверху и внизу окна

- **Активная точка** (вверху) — выберите точку, которую настраиваете.
  Все настройки ниже относятся к ней.
- **⟳ Сохранить и перезапустить** (внизу) — сохранить и сразу применить.
  **Нажимайте эту кнопку после любых изменений.**
- **💾 Сохранить** — сохранить, но применится только после перезапуска.
- **Закрыть** — закрыть без сохранения.

> _скрин: общий вид с вкладками_

## Вкладки — что где

**Валюты** — какие валюты показывать и в каком порядке.
Слева список всех валют, справа колонки табло. Выбрать валюту → указать колонку →
**→ Доб**. Убрать — **← Уб**. Порядок меняется стрелками **▲ ▼**.

**Заголовки** — надписи «Покупаем / Продаём» над колонками.
Каждая строка — отдельный язык.

**Размер табло** — ширина и высота в пикселях. Должны совпадать с реальным табло.

**Дизайн** — как всё выглядит: перетаскиваете блоки мышью, меняете шрифты, флаги, логотип.
Кнопки: **👁 Обновить превью** (посмотреть результат),
**📤 Отправить на табло** (отправить вручную).
Галочка **«Интернет постоянный»** — снимите, если на точке нет постоянного интернета
(тогда курсы шлются на табло вручную).

> _скрин: вкладка «Дизайн»_

**Сервис** — режимы работы и интервалы обновления. Без необходимости не трогать.

**Подключение** — связь с табло:
- **🔍 Проверить соединение** — на связи ли табло;
- **Питание табло:** 🔆 Включить · ⏻ Выключить · ↻ Перезагрузить;
- IP-адрес, модель контроллера, настройки FTP и API.

> _скрин: вкладка «Подключение» — питание и проверка связи_

**Дополнительно** — тонкие технические параметры (SDK, таймауты). Менять только при необходимости.

**Журнал** — список последних событий. Сюда смотрите, если что-то не работает.
Кнопка **«Обновить журнал»**.

## Частые задачи

| Что нужно | Куда идти |
|---|---|
| Поменять валюты / порядок | вкладка **Валюты** |
| Изменить надписи «Покупаем/Продаём» | вкладка **Заголовки** |
| Подвинуть элементы, шрифты, лого | вкладка **Дизайн** |
| Включить / выключить / перезагрузить табло | **Подключение → Питание табло** |
| Проверить связь с табло | **Подключение → Проверить соединение** |
| Точка без постоянного интернета | **Дизайн** → снять «Интернет постоянный» |
| Разобрать ошибку | вкладка **Журнал** |
| Добавить новую точку | файл **ADDING_POINT.md** |

> ⚠️ После изменений всегда нажимайте **«Сохранить и перезапустить»** —
> иначе настройки не применятся.
