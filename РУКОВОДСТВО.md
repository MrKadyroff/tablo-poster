# eCash Tablo — Руководство пользователя

Программа **eCash Tablo** управляет светодиодным табло с курсами валют:
получает актуальные курсы из API и отправляет готовое изображение на табло.

Программа работает в фоне. Её значок находится в системном лотке (трее) у часов —
синий кружок с буквой **e**. По значку доступны:

- **двойной клик** — открыть окно кассира («Управление курсами»);
- **правый клик** — меню: *Управление курсами*, *Настройки (администратор)*,
  *Перезапустить сервис*, *Выход*.

В меню также показан текущий статус сервиса:
🟢 **Работает** · 🟠 *Запускается / Останавливается* · 🔴 **Ошибка**.

> _скрин: значок в трее и контекстное меню_

## 👤 Инструкция для КАССИРА

Кассиру доступно одно простое окно — **«eCash Tablo — Курсы»**.
Дизайн табло и все настройки менять нельзя, только обновлять и отправлять курсы.

### Как открыть окно
Дважды кликните по значку eCash Tablo в трее **или** правый клик → **«Управление курсами…»**.
(На точках без постоянного интернета это окно открывается само при запуске программы.)

> _скрин: окно кассира_

### Что в окне
- **Точка: …** — название текущей точки (меняет только администратор).
- **Превью** — изображение, которое сейчас будет отправлено на табло.
- Две большие кнопки и строка статуса внизу.

### Порядок работы (2 шага)
1. **⟳ Обновить курсы из API** — программа запрашивает свежие курсы и
   перерисовывает превью. Дождитесь сообщения
   *«✓ Курсы обновлены ЧЧ:ММ:СС. Нажмите „Загрузить на табло“».*
2. **📤 Загрузить на табло** — отправляет изображение на табло.
   Дождитесь *«✓ …»* в строке статуса.

> _скрин: статус «Курсы обновлены» / «Загружено на табло»_

### Если что-то не так
- **✗ Ошибка получения курсов** — нет интернета или API недоступно.
  Проверьте сеть и нажмите **Обновить курсы** ещё раз.
- **✗ при отправке на табло** — табло выключено или нет связи с контроллером.
  Сообщите администратору.
- Кнопки заблокированы и курсор «песочные часы» — идёт операция, просто подождите.

> ⚠️ Закрытие окна (крестик) не выгружает программу — она продолжает работать в трее.
> Полностью выключать программу (меню → **Выход**) кассиру не нужно.

## 🛠️ Инструкция для АДМИНИСТРАТОРА

Полные настройки открываются через трей → **«Настройки (администратор)…»** и
защищены паролем администратора.

> _скрин: запрос пароля администратора_

Сверху окна — выбор **Активной точки**. Настройки ниже относятся к выбранной точке.
Внизу всегда доступны:
- **⟳ Сохранить и перезапустить** — сохранить и сразу применить (перезапуск сервиса);
- **💾 Сохранить** — сохранить без перезапуска (применится после перезапуска);
- **Закрыть** — закрыть окно без сохранения.

> _скрин: общий вид окна настроек с вкладками_

### Вкладки

**Валюты** — выбор валют и порядок их показа.
Слева список всех доступных валют, справа — колонки табло (до 3).
Задайте число колонок, выберите валюту, укажите колонку и нажмите **→ Доб**
(убрать — **← Уб**). Порядок внутри колонки меняется стрелками **▲ ▼**.

**Заголовки** — тексты «Покупаем / Продаём» для каждой колонки.
По одной строке на язык (например, казахский / русский / английский).

**Размер табло** — ширина и высота холста в пикселях.
Должны совпадать с физическим размером табло и настройками подключения.

**Дизайн** — визуальный редактор раскладки:
- блоки (курсы, флаги, логотип) перетаскиваются мышью, размер — за уголок;
- размеры шрифтов, флагов, логотипа, высота строк, X-координаты колонок;
- **⊞ Раскидка по размеру** — авторазмещение; **⊞ Лого по центру** — лого в центре;
- **⟳ Загрузить курсы из API** и **👁 Обновить превью** — проверка реального вида;
- **📤 Отправить на табло** — ручная отправка;
- галочка **«Интернет постоянный (автоотправка)»** — снимите для точек без
  постоянного интернета: тогда курсы обновляются, но на табло отправляют вручную
  (применяется после «Сохранить и перезапустить»).

> _скрин: вкладка «Дизайн» с редактором и превью_

**Сервис** — режим работы (RenderOnly / Uploader / Full), режим публикации,
интервалы опроса и обновления курсов, авто­отправка, тестовый режим
(не отправлять на табло), пропуск без изменений.

**Подключение** — связь с контроллером и сервисами:
- **🔍 Проверить соединение** — онлайн ли табло;
- **Питание табло:** 🔆 Включить · ⏻ Выключить · ↻ Перезагрузить контроллер;
- семейство и модель контроллера, IP-адрес, порт, тип подключения;
- параметры **FTP** (пользователь, пароль, порт, TLS);
- **API**: URL курсов, URL перезагрузки, порт REST API.

> _скрин: вкладка «Подключение» — проверка связи и питание_

**Дополнительно** — параметры SDK (логин/пароль, изолированный процесс),
число повторных попыток и таймауты, требование Wi-Fi/приватного IP,
отклонение несовпадения размера, пропуск дубликатов.

**Журнал** — последние события сервиса. Кнопка **«Обновить журнал»**.
Сюда смотрят при разборе ошибок.

> _скрин: вкладка «Журнал»_

### Добавление новой точки
Подробная пошаговая инструкция (папки контента, compose-конфиг, `screen.xml`,
`appsettings.json`) — в файле **ADDING_POINT.md**.

### Частые задачи
| Задача | Где |
|---|---|
| Сменить набор/порядок валют | вкладка **Валюты** |
| Поменять надписи «Покупаем/Продаём» | вкладка **Заголовки** |
| Подвинуть элементы, шрифты, лого | вкладка **Дизайн** |
| Включить/выключить/перезагрузить табло | **Подключение → Питание табло** |
| Проверить, на связи ли табло | **Подключение → Проверить соединение** |
| Точка без постоянного интернета | **Дизайн** → снять «Интернет постоянный» |
| Разобрать ошибку | вкладка **Журнал** |

> ⚠️ После изменений нажимайте **«Сохранить и перезапустить»**, иначе настройки
> не применятся к работающему сервису.
